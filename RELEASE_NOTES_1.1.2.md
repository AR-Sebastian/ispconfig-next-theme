# NEXT 1.1.2

First standalone public evaluation release of NEXT.

## Included

- Complete installable `next` theme directory
- Light and dark color schemes
- Responsive navigation, tables, filters and forms
- Dashboard and login presentation
- Configurable branding and accent colors
- German and English installation instructions
- SHA-256 checksums
