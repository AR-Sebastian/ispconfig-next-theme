# NEXT 1.2.0

## Deutsch

NEXT 1.2.0 ist die stabile, vollständig geprüfte Ausgabe des responsiven
Hell-/Dunkel-Themes für ISPConfig 3.3.1p1.

Geprüft wurden Ubuntu 22.04/24.04 und Debian 12/13 jeweils mit Apache und
Nginx. Die acht Plattformprofile bestanden 112 Laufzeitprüfungen ohne
Rückfall auf das Standardtheme. Zusätzlich wurden Administrator-, Reseller-,
Kunden- und Mailuser-Rechte, responsive Ansichten, Tabellen, Filter,
Formulare, Navigation, Dashboard-Metriken, Branding sowie Installation,
Aktualisierung, Sicherung und Rückkehr geprüft.

Das öffentliche Archiv enthält 303 Dateien: 300 Theme-Dateien und drei
rechtliche Hinweise.

## English

NEXT 1.2.0 is the stable, fully validated release of the responsive
light/dark theme for ISPConfig 3.3.1p1.

Ubuntu 22.04/24.04 and Debian 12/13 were tested with both Apache and Nginx.
All eight platform profiles passed 112 runtime checks without falling back to
the default theme. Administrator, reseller, customer and mail-user
permissions, responsive layouts, tables, filters, forms, navigation,
dashboard metrics, branding, installation, upgrade, backup and rollback were
also validated.

The public archive contains 303 files: 300 theme files and three legal notices.
