# ISPConfig NEXT 1.2.2

Version 1.2.2 is the public-product and localization maintenance release for
ISPConfig 3.3.1p1.

## Changes

- neutral ISPConfig NEXT identity without private laboratory wording;
- German and English login, helper and accessibility copy;
- language-aware table, filter and pagination messages;
- localized system-settings headings;
- accurate authentication copy without a fixed two-factor promise;
- consistent web app and accessible SVG product names.

## Validation

- all 300 packaged files verified with SHA-256 checksums;
- standalone runtime and package gates passed;
- administrator, reseller, customer and mail-user boundaries passed on Debian
  12 with Apache and Nginx;
- the broader ISPConfig 3.3.1p1 platform matrix remains valid for Ubuntu
  22.04/24.04 and Debian 12/13 with Apache and Nginx.

The immutable `v1.2.1` tag is retained unchanged. Installations should use
`v1.2.2` for the corrected public presentation.
