# NEXT 1.2.3

NEXT 1.2.3 is a maintenance release for ISPConfig 3.3.1p1. It completes
responsive labels in dashboard quota and account-limit tables, documents the
optional global sign-in theme, and aligns public metadata and runtime evidence.

The standalone package was validated on ISPConfig 3.3.1p1. Historical OpenVZ,
APS Installer, Mailman 2 and XMPP surfaces are not shipped or presented by the
theme; defensive navigation boundaries remain because the unchanged ISPConfig
core can still emit historical links.
